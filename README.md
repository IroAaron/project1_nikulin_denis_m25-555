# project1_nikulin_denis_m25-555

# Игра лабиринт сокровищ

# Стартовый boot файл - main.py.
# Файл со всеми константами - constants.py
# Player_actions.py - файл с реализацией взаимодействия игрока с игрой
# Utils.py - файл с дополнительным функционалом

# Описание: Ходи по подземному лабиринту, собирай вещи, решай загадки, отбивайся от чудовищ и найди сокровище, сопрятанное в глубине лабиринта
# Управление: Клавиатура: Команды: help, go, look, take, use, inventory, use, solve, quit 

# Установка и распределение зависимостей: make install
# Запуск проекта: make install
